## Overview

This repository contains my coursework, notebooks, reports, and projects completed as part of the **AnalystLab Africa Machine Learning Internship**.

The internship focuses on building practical machine learning skills through hands-on projects covering:

- Machine Learning Fundamentals
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Supervised Learning
- Unsupervised Learning
- Model Evaluation
- Model Optimization
- Final Machine Learning Project

All work is completed using **Google Colab**, **Python**, and **GitHub**.
