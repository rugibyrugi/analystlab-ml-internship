# Datasets Used

## Titanic Dataset

**Problem Type:** Binary Classification

**Target Variable**

- Survived

**Features**

- Passenger Class
- Sex
- Age
- Fare
- Number of Siblings/Spouses
- Number of Parents/Children
- Port of Embarkation

---

## Iris Dataset

**Problem Type:** Multi-class Classification

**Target Variable**

- Species

**Features**

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## California Housing Dataset

**Problem Type:** Regression

**Target Variable**

- Median House Value

**Features**

- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude

# Installation

Clone the repository:

```bash
git clone https://github.com/your-username/analystlab-ml-internship.git
```

Navigate into the project directory:

```bash
cd analystlab-ml-internship
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook or upload the notebooks to Google Colab.
